# AgriTech — Core Java Terminal Backend

This is Phase 1 of the project.

Everything in this phase is Java:
- Core Java
- OOP
- Classes/Objects
- Inheritance
- Polymorphism
- Interfaces
- Collections
- Exception Handling
- File I/O
- Terminal UI

No frontend, Spring Boot, MySQL, or real API is required yet.

## Run
Requirements: JDK 17+, Maven

```bash
mvn clean compile
mvn exec:java
```

## Terminal modules
1. Farmer Registration
2. Farmer Profile
3. Find Best Crops
4. Smart Sowing Advisor
5. Profit Calculator
6. Mandi Prices
7. Equipment Rental
8. Loan EMI
9. 7-Day Weather
0. Exit
