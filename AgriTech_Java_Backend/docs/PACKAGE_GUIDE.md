# Package Guide

`com.agritech.app`
- Main terminal application

`com.agritech.model`
- Farmer
- DailyForecast
- MandiPrice
- Loan
- CropRecommendation
- SowingAdvisory

`com.agritech.model.crop`
- Crop abstract class
- Wheat, Rice, Maize, Mustard

`com.agritech.model.equipment`
- FarmEquipment interface
- BaseEquipment abstract class
- Tractor, Harvester, IrrigationPump, Rotavator

`com.agritech.enums`
- SoilType
- RiskLevel
- WaterRequirement

`com.agritech.repository`
- FarmerRepository
- FileFarmerRepository

`com.agritech.service`
- FarmerService
- CropCatalogService
- WeatherService
- DemoWeatherService
- MandiService
- ProfitService
- EquipmentService
- LoanService

`com.agritech.engine`
- CropRecommendationEngine
- SowingDecisionEngine

`com.agritech.data`
- DemoData

`com.agritech.exception`
- custom exceptions

`com.agritech.util`
- helper classes
